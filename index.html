Objectives

  1. 1.1 To digitize burial records.
  2. 1.2 To create GIS grave mapping.
  3. 1.3 To implement online grave booking portal.
  4. 1.4 To implement a centralized spatial database for storing grave coordinates and burial records.

Digitized burial records

The system captures and stores burial information electronically, improving accuracy, traceability, and record retrieval.

GIS grave mapping

Spatial mapping allows cemetery staff to locate graves, identify available plots, and manage cemeteries more effectively.

Online grave booking portal

The platform provides a public portal that supports online grave requests and efficient booking procedures.

Centralized spatial database

A centralized database preserves burial records and grave coordinates in one secure system for reporting and future decisions.
